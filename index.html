Enerlytics

An intelligent energy forecasting dashboard that predicts daily electricity consumption using Multiple Linear Regression and estimates monthly cost for improved planning.

Problem Statement

Electricity consumption in households is often inefficient, leading to higher electricity bills and energy wastage. Most users lack tools to predict future consumption accurately. This project develops a regression-based forecasting system that predicts next-day usage and estimates monthly billing cost.

Literature Review

Some research papers use machine learning to predict energy consumption, but many solutions are complex, expensive, or not user-friendly.

Research Gap / Innovation

Enerlytics provides a lightweight, interpretable Multiple Linear Regression model with real-time visualization and cost estimation for practical users.

System Methodology

Dataset

365 daily records with temperature and energy values.

Model

Multiple Linear Regression using Time + Temperature.
