Enerlytics

"An intelligent energy forecasting dashboard that predicts daily electricity consumption using Multiple Linear Regression and estimates monthly cost for improved planning and analysis."

Problem Statement

Electricity consumption varies due to temperature and usage patterns. Manual estimation of future consumption leads to inaccurate billing predictions and poor planning. This project aims to build a machine learning-based forecasting system that predicts next-day energy usage and estimates monthly electricity cost efficiently.

System Methodology

Dataset

365 daily records containing temperature and energy consumption values.

Model Used

Multiple Linear Regression using Time Index and Average Temperature.
