Enerlytics

An intelligent energy forecasting dashboard that predicts daily electricity consumption using Multiple Linear Regression and estimates monthly cost for improved planning.

Problem Statement

Electricity consumption in households is often inefficient, leading to higher electricity bills and unnecessary energy wastage. Homeowners usually lack accurate tools to predict their future energy usage, which makes planning difficult. This project aims to develop a machine learning-based forecasting system that predicts next-day electricity consumption using historical data and estimates monthly cost. The system helps users optimise their energy usage, reduce expenses, and promote sustainable consumption.

Literature Review / Market Research

Existing energy monitoring systems mainly track usage and show basic statistics. Some research papers use machine learning to predict energy consumption, but many solutions are complex, expensive, or not user-friendly. Most systems do not provide simple insights that common users can easily understand.

Research Gap / Innovation

Enerlytics provides a lightweight, interpretable Multiple Linear Regression model with real-time visualization and cost estimation for practical users.

System Methodology

Dataset

365 daily records with temperature and energy values.

Model

Multiple Linear Regression using Time + Temperature.
