Enerlytics

An intelligent energy forecasting system that predicts hourly electricity consumption using Random Forest Regression across 8 real-world features — enabling accurate cost estimation and energy optimisation.

Open ML Dashboard ↗

Problem Statement

Electricity consumption in households and commercial spaces is highly variable and difficult to forecast accurately. Traditional tools rely on linear assumptions and only use 1–2 features, missing key energy drivers like occupancy, HVAC state, and renewable generation. This project builds a Random Forest-based forecasting system trained on 1,000 real records across 8 features — predicting next-hour energy consumption and monthly billing cost with higher accuracy than single-variable approaches.

Literature Review / Market Research

Existing ML-based energy systems are complex, cloud-dependent, and inaccessible to everyday users. Enerlytics provides a lightweight, fully browser-based Random Forest solution deployable without any backend infrastructure — just a static GitHub Pages site.

Research Gap / Innovation

Most lightweight tools ignore discrete features (HVAC On/Off, Holiday flags) and non-linear interactions. Enerlytics implements a full RF ensemble pre-trained in Python (scikit-learn) and exported to JSON — with live feature importance, real-time prediction, and cost estimation in a single deployable HTML file.

System Methodology

🗄️
Dataset / Input

1,000 hourly records · 8 features: Temperature, Humidity, Square Footage, Occupancy, HVAC Usage, Lighting Usage, Renewable Energy, Holiday flag. Target: EnergyConsumption (kWh). 80/20 train-test split.

🧠
Model / Architecture

Random Forest Regression — ensemble of 50 decision trees trained in Python (scikit-learn). Each tree uses a bootstrap sample with random feature subsets. Final prediction = average of all 50 trees. Handles non-linearity natively.

💻
Live Execution

Model pre-trained in Python, exported as JSON. Dashboard runs inference entirely in the browser — no server required.
